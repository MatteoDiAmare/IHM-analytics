Teknik för digitala plattformar

Här ser du hur en webbplats eller app hänger ihop: vad som händer när någon klickar, hur data rör sig och hur det kan mätas. Du provar i webbläsaren, tittar på vad som hände och bygger sedan vidare själv.

Börja från grunden Välj ett moment

Kursens helhet: från klick till svar

Det som händer när någon klickar är en kedja. Mätningen sitter bredvid kedjan och lyssnar på samma händelse.

Handlingen

  1. Användare: någon vill göra något.
  2. Handling: personen klickar eller skickar ett formulär. Webbläsaren registrerar det som en händelse i sidan (DOM).
  3. JavaScript: din kod lyssnar på händelsen och bestämmer vad som ska hända.
  4. Request: koden skickar en förfrågan till servern.
  5. Server: tar emot, kontrollerar och utför jobbet.
  6. Lagring: resultatet sparas.
  7. Response: servern svarar och sidan visar vad som hände.

Mätkedjan

  1. Mätpunkt: händelsen beskrivs i dataLayer.
  2. Trigger och tagg: en tagghanterare avgör om och när mätningen körs. Samtycke kan stoppa den.
  3. Insamling: uppgifterna når ett mätverktyg och blir underlag för rapporter.

Tracking är en mätkedja. Handlingen fungerar också när mätningen saknas eller stoppas, till exempel för att besökaren inte har gett samtycke.

Tre exempel som vi återkommer till

  • Musikspelare

    Spela, pausa och spara i en spellista. Bra för att förstå händelser och request.

  • Webbshop

    Lägg i varukorg och gå till kassan. Bra för att förstå data, identifierare och mätning av köp.

  • Formulär

    Fyll i, skicka och få ett svar. Bra för att förstå HTML, validering och samtycke.

Kursens fem lärandemål

Efter kursen ska du kunna:

  1. Redogöra för plattformars uppbyggnad på server och klient ur ett datainsamlingsperspektiv.
  2. Redogöra för datainsamling genom identifiering och spårning.
  3. Redogöra för grundläggande JavaScript och dess användningsområden.
  4. Använda grundläggande HTML.
  5. Analysera, implementera och modifiera kod för identifiering och spårning.

Välj ett moment

Bygg och förstå

  • Digitala plattformar

    Se hur klient, server och lagring samverar i en webbplats eller app.

  • HTML, CSS och DOM

    Bygg sidans delar och lär dig hur webbläsaren gör dem till något du kan undersöka.

  • JavaScript och händelser

    Låt sidan reagera på klick och formulär och se vilken data som uppstår.

  • HTTP, API och Network

    Förstå requests och responses och följ dem i webbläsarens Network-flik.

Samla in och förstå data

  • Cookies och webbläsarlagring

    Jämför cookies, localStorage och sessionStorage och se vad de passar till.

  • Identifiering

    Se hur samma besökare eller användare kan kännas igen över flera besök.

  • Tracking och dataLayer

    Beskriv en händelse en gång i dataLayer och låt mätningen läsa den.

  • Tagghantering

    Styr mätning med taggar, triggers och variabler utan att ändra sidans kod varje gång.

  • Samtycke

    Se hur ett val av besökaren styr vad som får samlas in.

  • Datainsamling på klient och server

    Jämför vad som kan samlas in i webbläsaren och på servern.

Analytics och sökbarhet

  • Så arbetar du med Google Analytics 4

    Mät rätt saker i rätt ordning: från fråga till installation, kontroll och rapport.

  • Search Console och indexering

    Hur Google hittar, indexerar och visar din webbplats, och vad som påverkar det.

  • Tillgänglighet på webben

    Att alla kan uppfatta, förstå och använda sidan, och hur det hänger ihop med sökbarhet och mätning.

Arbeta praktiskt

  • Verktyg och arbetsflöde

    Var VS Code, terminalen, localhost, DevTools och GitHub hör hemma.

  • Felsökning

    Ett arbetssätt för att hitta vad som faktiskt händer och rätta det.
