HTML, CSS och DOM

HTML beskriver vad som finns på sidan, CSS hur det ser ut och DOM är webbläsarens levande modell av sidan som JavaScript kan läsa och ändra. Knappar, länkar och formulär finns här, och det är dem som händelser och mätning utgår från.

Det här kan du efteråt

  • Skriva enkel HTML med rubriker, länkar, knappar och formulär.
  • Läsa sidans DOM i Elements-fliken.
  • Förstå att id, class och data-attribut används av både script och taggar.

Ett litet formulär

Tre roller

HTML (markup)
Beskriver innehållet och dess struktur: rubriker, stycken, länkar, formulär.
CSS (styles)
Beskriver utseendet: färger, avstånd, layout. Kopplas till element med selektorer.
DOM (document object model)
Webbläsarens träd av element som JavaScript kan läsa och ändra.
Element (element)
En byggsten i HTML, till exempel en knapp eller en rubrik.
Attribut (attribute)
Extra information på ett element, som id eller href.
Selektor (selector)
Ett uttryck som pekar ut element, till exempel #epost eller .knapp.

Attribut som både script och mätning använder

Prova i webbläsaren

  1. Högerklicka på en rubrik på valfri sida och välj Inspektera. Du hamnar i fliken Elements.
  2. Dubbelklicka på rubrikens text i Elements och skriv något annat. Sidan ändras direkt.
  3. Klicka på ett element och titta i Styles till höger. Slå av och på en CSS-regel med rutan.
  4. Ladda om sidan. Ändringarna försvinner: du ändrade webbläsarens DOM, inte filen på servern.

Vanliga misstag

  • Två element med samma id. Det ska vara unikt, annars hittar scriptet fel element.
  • Ett fält utan label. Det blir svårt att använda och svårt att mäta rätt.
  • Att förväxla filen med DOM:en. Det som visas i Elements kan skilja sig från källkoden, eftersom JavaScript kan ha ändrat sidan.
