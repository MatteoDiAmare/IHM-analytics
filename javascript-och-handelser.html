JavaScript och händelser

JavaScript gör att sidan kan reagera. En händelse (event) inträffar, till exempel ett klick, och din kod väljer vad som ska hända. Samma händelser används för att få sidan att fungera och för att mäta den.

Det här kan du efteråt

  • Redogöra för vad JavaScript används till på webbplatser.
  • Lyssna på klick och formulärinskick.
  • Skriva ut och undersöka data i Console.

Begrepp

Event (event)
Något som händer, som ett klick eller ett inskick.
Event listener (event listener)
Kod som körs när ett visst event inträffar.
Console
DevTools-flik där du skriver och läser JavaScript direkt.
Callback (callback)
Funktionen som skickas med till addEventListener och körs när eventet inträffar.

Prova i webbläsaren

  1. Öppna en sida, tryck F12 och välj fliken Console.
  2. Skriv document.title och tryck Enter. Du läser sidans titel.
  3. Skriv document.querySelectorAll('a').length. Hur många länkar finns det?
  4. Markera ett element i Elements och skriv $0 i Console. Då får du just det elementet.

Vanliga misstag

  • Cannot read properties of null: querySelector hittade inget, ofta för att scriptet körs innan elementet finns eller för att selektorn är felstavad.
  • Glömd preventDefault(): formuläret laddar om sidan innan din kod hunnit göra något.
  • Att lyssna på fel element. Ett klick på texten i en knapp skickar eventet vidare upp (bubblar), så kontrollera event.target när du är osäker.
