Verktyg och arbetsflöde

Här får verktygen sin plats i arbetet: VS Code för att skriva, terminalen för att köra, localhost för att se sidan lokalt, DevTools för att undersöka och GitHub för att spara och dela.

Det här kan du efteråt

  • Förklara vad varje verktyg används till.
  • Öppna ett projekt lokalt och se det i webbläsaren.
  • Följa ett vanligt arbetspass från kod till delad version.

Ett vanligt arbetspass

  1. VS Code: öppna projektmappen och skriv eller ändra filer.
  2. Se sidan lokalt: öppna den via en lokal server (se nedan).
  3. DevTools: tryck F12 och undersök Elements, Console, Network och Application.
  4. Git och GitHub: spara ändringen med en commit och skicka den till GitHub.
  5. GitHub Pages: när ändringen ligger på main publiceras sidan automatiskt.

Visa sidan lokalt utan Node

Den här siten är ren HTML, CSS och JavaScript och kräver inget byggsteg. Två enkla sätt att se den lokalt:

  • I VS Code: installera tillägget Live Server och välj Open with Live Server på index.html.
  • Eller dubbelklicka på index.html. Det fungerar för enkla sidor, men vissa webbläsarfunktioner (cookies, fetch) beter sig annorlunda på file:// än på en riktig adress, så använd helst en lokal server.

Har du Node installerat går det också: npx http-server i projektmappen startar en lokal server. Det behövs inte för den här siten.

Spara och dela med Git

Begrepp

localhost
Adressen till din egen dator. En sida på localhost syns bara för dig.
DevTools
Webbläsarens verktyg för att undersöka sidor. Öppnas med F12.
Git och GitHub
Git håller reda på ändringar. GitHub är tjänsten där koden lagras och delas.
GitHub Pages
Gratis hosting av statiska sidor direkt från ett repo.

DevTools-flikarna i den här kursen

  • Elements

    Se och ändra sidans DOM och CSS.

  • Console

    Läsa felmeddelanden och köra JavaScript.

  • Network

    Se varje request och response.

  • Application

    Se cookies, localStorage och sessionStorage.
